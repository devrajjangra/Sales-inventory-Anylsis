Data Analytics Project
📌 Project Overview
This project focuses on analyzing business data to identify important trends, patterns, and insights using SQL, Python, Excel, and Power BI.
The project includes data cleaning, exploratory data analysis (EDA), SQL analysis, and an interactive Power BI dashboard.

🛠️ Tools & Technologies
- SQL – Data querying and analysis
- Python – Data cleaning and exploratory data analysis
- Pandas & NumPy – Data manipulation and analysis
- Matplotlib & Seaborn – Data visualization
- Excel – Data analysis and preprocessing
- Power BI – Interactive dashboard and visualization
- PostgreSQL – Database management

📂 Dataset
The project contains the following CSV files:
1. "begin_inventory.csv"
2. "end_inventory.csv"
3. "sales.csv"
4. "purchases.csv"
5. "purchase_prices.csv"
6. "vendor_invoices.csv"

These datasets contain information related to inventory, sales, purchases, pricing, and vendors.

🔍 Project Workflow
1. Data Collection
Collected and organized multiple CSV datasets containing business transaction and inventory information.

2. Data Cleaning
- Handled missing values
- Checked duplicate records
- Standardized data types
- Cleaned inconsistent data
- Prepared datasets for analysis

3. SQL Analysis
Used PostgreSQL to:
- Join multiple datasets
- Analyze sales and purchases
- Analyze inventory
- Calculate business metrics
- Identify trends and patterns

4. Exploratory Data Analysis
Python libraries were used to explore the datasets and identify patterns through statistical analysis and visualizations.

5. Power BI Dashboard
Created an interactive dashboard to visualize key business metrics and insights.
